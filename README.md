# Haptic OGG

把普通音频转成 3 声道 Vorbis `.ogg`：第 3 声道是一条低频触觉轨道（默认 45–180 Hz、音量 0.65），
并写入 `android_haptic=1`，让系统在播放该文件时同步驱动振动。全程本地处理，应用没有网络权限。  
人话就是你设置的铃声可以同步振动而且振动在硬物体表面可以使其发声。  
本项目使用DeepSeek-V4-Flash生成，消耗token 127,131,844，花费6.81CNY。

Switch to [English](README.en-US.md) version.

## 构建

```bash
./gradlew assembleDebug        # Windows: .\gradlew.bat assembleDebug
```

产物在 `app/build/outputs/apk/debug/app-debug.apk`（约 126 MB，依赖包含全部编解码器）。Gradle 与依赖
缓存就绪时可以加 `--offline`。依赖只有 `com.arthenica:ffmpeg-kit-full-gpl:6.0-2`：上游已停止维护，
同步失败需换可用的 fork 或自行编译带 `libvorbis` 的 FFmpeg Android 库；这是 GPL 版本，分发 APK 前
确认许可证义务。

## 使用方法

1. **首次启动**会打开「导出音频授权」页面：是否允许把每次转换的结果自动保存到系统音乐目录。
   - 「同意」→ 保存到 `音乐/HapticOgg`（Android 9 及以下会先申请存储权限）。
   - 「不同意」→ 稍后用「修改导出文件位置」自己选文件夹。用返回手势离开该页面等同于「不同意」。
2. **1 · 选择音频** → 「选择音频（可多选）」。再次选择是**追加**；每行有「移除」，有选择时才显示
   「清空选择」，添加/移除/清空都用 Toast 提示。系统选择器没有取消按钮，直接返回不会破坏已有选择，
   回到应用改列表即可。
3. **2 · 导出位置** → 「修改导出文件位置」：系统音乐目录，或自选任意文件夹。文件夹授权会持久化，
   选择器从当前文件夹开始，直接返回不改变原有位置。
4. **3 · 转换与测试** → 「开始转换」。转换在后台逐个文件进行，状态栏显示 `正在转换 x/n：文件名`，
   结束后给出成功数量与每个失败文件的详情（含 FFmpeg 输出）；没选文件时点击只用 Toast 提醒。
   - 处于自选文件夹模式但还没选文件夹时，会先询问：现在选文件夹（选完立即开始转换）、改用音乐目录，
     或取消。
5. **已转换文件**：最新在前，默认 5 条，点「显示更多」后继续滚动会自动翻页。点条目打开播放测试
   （播放/暂停、拖动进度、设为铃声）；左滑超过行宽约 45% 松手会弹确认框再删除。
6. 「测试振动（播放）」= 对最近一次转换结果打开播放测试。

播放测试会保持触觉声道开启，Android 12+ 由系统用文件本身生成振动；不支持触觉播放的设备（例如转子
马达）只能试听音频。应用内播放的振动强度可能比系统来电时弱。

## 输出位置

| 内容 | 位置 |
| --- | --- |
| 本地副本（列表来源） | `Android/data/com.example.hapticogg/files/converted/`，卸载应用即消失 |
| 音乐目录导出副本 | `Music/HapticOgg/`（Android 10+ 走 MediaStore，9 及以下写公共目录并 MediaScanner 加入媒体库） |
| 自选文件夹导出副本 | 你所选文件夹内的同名文件（SAF） |
| 铃声副本 | `Ringtones/HapticOgg/` |

文件名为 `<原文件名去掉扩展名>_<yyyyMMdd_HHmmss>.ogg`；原文件名里的 `\ / : * ? " < > |` 与控制字符
替换成 `_`，主干最长 80 字符，为空则用 `audio`。公共目录与自选文件夹重名时自动加 `_2`、`_3`；走
MediaStore 时由系统决定。删除一条记录会同时删除本地副本、遗留的 `<名字>.env` 包络文件，以及能匹配到
的导出副本（同名或相同 `_yyyyMMdd_HHmmss.ogg` 时间戳后缀，含铃声目录与自选文件夹）。

## 权限

- `VIBRATE`、`WRITE_SETTINGS`：把文件设为系统铃声。
- `WRITE_EXTERNAL_STORAGE`（`maxSdkVersion="28"`）：只有 Android 9 及以下写公共音乐目录时才需要。

## 注意事项与排查

- 来电时是否同步播放触觉取决于厂商与系统版本：3 声道加 `android_haptic=1` 并不保证所有设备都会启用，
   系统铃声设置与触觉音频支持是两回事。
- 同步振动要求 Android 12+ 且 `AudioManager.isHapticPlaybackSupported()` 为 true（线性马达）；
   转子马达设备只能试听音频。
- 振动只在播放期间生效，中途消失时暂停再播放即可。
- 「设为铃声」没反应时，先确认已授予「修改系统设置」权限：应用会跳转到该设置页，回来后再点一次
   「设为铃声」。
- 列表里每行的「导出副本在 / 导出副本已不存在」是按媒体库与所选文件夹里的同名文件匹配出来的；被手动
   删除、或属于其它应用的条目会显示为不存在，也无法在应用内删除。
- 构建/同步失败先看依赖：FFmpegKit 上游已停止维护，需要可用的镜像或 fork。

## 代码结构（速查）

按职责分包：`ui/`（页面与列表控件）、`conversion/`（FFmpeg 命令与批量转换）、`export/`（写入音乐库、
自选文件夹、铃声）、`data/`（偏好设置与本地文件）。
